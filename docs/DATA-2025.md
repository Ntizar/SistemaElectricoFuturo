# Datos 2025 y Fuentes

## Objetivo

Dejar trazabilidad de los datos de referencia usados como punto de partida para la v3.

## Variables base incluidas en `js/constants.js`

| --- | --- | --- |
| `demanda` | 248 TWh | Aproximacion peninsular para referencia 2025 |

## Fuentes oficiales a revisar y consolidar

- REE datos del sistema: https://www.ree.es/es/datos
- OMIE mercado diario: https://www.omie.es/
- MITECO PNIEC: https://www.miteco.gob.es/es/energia/temas/planificacion/plan-nacional-integrado-energia-clima.html
- CNMC peajes y cargos: https://www.cnmc.es/ambitos-de-actuacion/energia/peajes-y-cargos
- ENTSO-E Transparency: https://transparency.entsoe.eu/
- EU ETS: https://climate.ec.europa.eu/eu-action/eu-emissions-trading-system-eu-ets_es

## Estado actual

- Los datos estan preparados como referencia de simulacion, no como dataset auditado fila por fila.
- Antes de una version publica cerrada conviene contrastar todos los campos con el informe anual 2025 definitivo de REE y con OMIE.
- Si se valida una cifra distinta, la fuente de verdad debe actualizarse en `js/constants.js` y en este archivo.
